UI / UX Design Prompt

Design a modern, production-quality user interface for a web application called MIC Event Report Generator.

Do not implement backend functionality. Focus entirely on the UI, interactions, layouts, design system, responsiveness, animations, and user experience.

The application should feel polished enough to be used daily by students organizing events at VIT Chennai.


---

Overall Design Philosophy

The UI should feel like a combination of:

Tally.so (conversational forms)

Linear (clean, professional interface)

Notion (minimal, document-focused)


The application should not resemble:

College ERP systems

Government portals

Microsoft Forms

Google Forms

Dashboard-heavy admin templates


The experience should feel calm, minimal, and enjoyable.


---

Visual Identity

The interface should prioritize simplicity over decoration.

Design principles:

Large whitespace

Clear typography

One primary action at a time

Minimal distractions

Clean alignment

Consistent spacing

Fast and intuitive navigation


The UI should feel premium without trying to look futuristic.


---

Theme

Light mode only.

Background:

Soft off-white


Cards:

Pure white


Text:

Near black


Secondary text:

Neutral gray


Borders:

Very subtle


Rounded corners:

Approximately 10–12px


Shadows:

Extremely light

Almost invisible



---

Accent Color

The accent color should be configurable.

For now:

Do NOT use purple.

Do NOT use Microsoft's default blue.

Avoid flashy colors.


Use a muted, professional accent that works well with a minimal interface.

Accent colors should only appear on:

Primary buttons

Focus states

Selected options

Links

Progress indicators


Everything else should remain mostly monochrome.


---

Typography

Use Inter throughout the application.

Hierarchy should rely on:

Weight

Size

Spacing


Avoid decorative fonts.


---

Icons

Use Lucide Icons.

Only outline icons.

Consistent stroke width.

Minimal icon usage.


---

Animations

Animations should be subtle.

Examples:

Gentle fade transitions

Small slide animations

Smooth progress updates


Avoid:

Bounce animations

Large page transitions

Excessive motion

Flashy loading effects



---

Landing Page

The landing page should be extremely minimal.

Display only:

Application title

Two primary actions


Actions:

Start New Report

Upload Report


No marketing text.

No feature lists.

No testimonials.

No statistics.

No recent reports.

No unnecessary information.


---

Hero Illustration

Include a small decorative illustration near the title.

The illustration should not dominate the page.

Possible concepts:

Pixel-art document assembling itself

Stacked papers

A small printer printing a report

A tiny document robot

A clipboard with papers


Style:

Pixel art

Minimal

Mostly monochrome

One small accent color

Clean

Friendly

Static or very subtle idle animation


Avoid:

Large illustrations

Cartoon characters

Anime

Space themes

Generic AI artwork

3D graphics

Overly playful visuals


The illustration should simply add personality without distracting from the primary action.


---

Login

Simple centered card.

Fields:

Username

Password


Primary button:

Login

No sign-up.

No forgot password.

No social logins.

Authentication determines whether the user enters:

User workspace

Admin workspace


The UI should not expose separate login pages.


---

Report Creation Experience

The report creation experience should feel conversational.

Present one primary question or section at a time rather than displaying a massive form.

Large whitespace.

Minimal distractions.

Smooth transitions between questions.

Progress should always be visible but understated.

Avoid overwhelming the user.


---

Review Experience

The review screen should present all collected information grouped by section.

Each section should display:

Summary

Completion state

Ability to edit


Editing should not restart the workflow.

Users should easily modify individual sections before generating the final report.


---

Preview

Before download, provide a clean document preview experience.

The preview should resemble a document viewer rather than an editor.

The focus is reviewing rather than editing.


---

Admin Interface

The admin interface should use the same design language.

Minimal.

Clean.

Professional.

Avoid dashboard clutter.

Admin pages should include areas for managing:

Uploaded reports

Templates

Logos

Faculty

Assets

Settings


The design should prioritize usability over visual complexity.


---

Responsive Design

Desktop-first.

Tablet support.

Mobile should remain fully usable.

Maintain generous spacing across screen sizes.


---

Accessibility

Ensure:

Good contrast

Keyboard navigation

Visible focus states

Appropriate spacing

Readable typography



---

Things to Avoid

Do not use:

Purple

Generic AI gradients

Neon colors

Glassmorphism

Heavy shadows

Rounded bubble UI

Excessive animations

Cluttered dashboards

Generic SaaS hero sections

Marketing-heavy landing pages

Large illustrations

Multiple competing primary actions



---

Overall Goal

Design an interface that feels timeless, calm, and efficient.

A user should feel like they are filling out a well-designed document rather than interacting with an administrative system. The interface should stay out of the user's way, allowing them to complete and review an event report with minimal friction while maintaining a polished, memorable identity.
